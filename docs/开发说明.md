## 发布元数据

项目名和源码目录保留 `FolderQuick` 作为内部开发名；用户看到的公开应用名统一为“边边文件夹”。发布相关字段只从下面两份文件维护：

- `ReleaseMetadata.xcconfig`：Xcode 工程和 `AppInfo.plist` 的来源。
- `release_metadata.sh`：命令行构建脚本和 DMG 打包脚本的来源。

当前发布约定：

```text
公开应用名：边边文件夹
内部可执行文件名：FolderQuick
bundle id：com.bianbian.folderquick
版本号：1.0.1
build 号：101
DMG 文件名：BianbianFolder-1.0.1-universal.dmg
最低系统版本：macOS 13.0
```

以后发新版时，优先修改 `ReleaseMetadata.xcconfig` 和 `release_metadata.sh`，不要直接在 `AppInfo.plist`、Xcode 工程或打包脚本里手写版本号。

## 构建方式

推荐使用 Xcode 工程构建：

```bash
cd app/FolderQuick
./build_xcode.sh
```

构建产物：

```text
app/FolderQuick/build/XcodeDerived/Build/Products/Release/边边文件夹.app
```

旧的 Swift Package 构建脚本仍保留，用于快速验证：

```bash
cd app/FolderQuick
./build_app.sh
```

生成 DMG：

```bash
cd app/FolderQuick
./package_dmg.sh
```

DMG 产物：

```text
dist/BianbianFolder-1.0.1-universal.dmg
```

## 源码说明

- `main.swift`：应用入口、菜单栏图标、主控制器启动。
- `SidebarWindowController.swift`：主窗口、标签页、文件区、设置应用、拖拽和快捷操作。
- `SettingsPanel.swift`：设置窗口。
- `Models.swift`：文件模型、设置模型、日志工具。
- `FolderStore.swift`：常用文件夹和设置保存。
- `FileLoader.swift`：文件读取、类型判断、文件信息。
- `FileCollectionView.swift`、`FileItemView.swift`：图标视图。
- `FileOutlineView.swift`、`FileListRowView.swift`：列表视图。
- `FileDropScrollView.swift`、`FilePasteboardReader.swift`：拖入拖出文件。
- `FileTransferProgressPanel.swift`：文件复制或移动进度。
- `EdgeTriggerView.swift`：边缘触发区域。
- `GlobalHotkey.swift`：全局快捷键。

## 日志

运行时日志写入：

```text
~/Library/Application Support/FolderQuick/FolderQuick.log
```

如果出现卡死、设置不生效、拖拽异常，优先看这份日志。日志里会记录启动、读取文件、筛选排序、设置保存、列表列切换、边缘触发等关键节点。

## 当前技术路线

- 语言：Swift。
- 界面：AppKit。
- 文件预览：Quick Look。
- 缩略图：QuickLookThumbnailing。
- 文件拖拽：macOS Pasteboard 和 dragging API。
- 设置保存：本地 JSON 和 UserDefaults。
